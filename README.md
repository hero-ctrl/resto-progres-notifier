# نظام التنبيهات الذكي لحجز وجبات الإطعام الجامعي (Progrès) 🍽️

نظام آلي مخصص للطلبة الجامعيين لتذكيرهم بحجز وجبات المطعم الجامعي عبر تطبيق WebEtu / Progrès كل 3 أيام وفق دورة الحجز الرسمية.

## 🌟 مميزات النظام
- **يعمل سحابياً 24/7:** عبر GitHub Actions دون الحاجة لفتح الحاسوب أو الهاتف.
- **تنبيهات فورية ومجانية:** عبر تطبيق [ntfy](https://ntfy.sh) المتاح على أندرويد وiOS والمتصفح.
- **3 دفعات تذكيرية متدرجة الأهمية:**
  - ☀️ **الدفعة 1 (10:30 صباحاً):** تذكير صباحي هادئ.
  - ⚠️ **الدفعة 2 (17:30 مساءً):** تنبيه لمتابعة الحجز قبل انتهاء اليوم.
  - 🚨 **الدفعة 3 (21:30 ليلاً):** إنذار أخير بأعلى درجة أولوية وصوت تنبيه قوي قبل غلق الحجز عند منتصف الليل.
- **زر انتقال مباشر:** كل إشعار يحتوي على زر يفتح تطبيق WebEtu / Progrès مباشرة لتسجيل الدخول والحجز فوراً.
